# Task 5: Exploratory Data Analysis (EDA) – Titanic Dataset

## 📌 Objective
Perform EDA on the Titanic dataset to identify trends, patterns, and insights in the data.

## 📁 Dataset
Titanic dataset (CSV) containing passenger details and survival status.

## 🛠️ Tools Used
- Python 3
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 What was done
- Loaded the dataset
- Explored basic statistics and data structure
- Handled missing values
- Visualized distributions and relationships
- Extracted key insights from plots

## 📈 Key Insights
- Most passengers did not survive.
- Females had a higher chance of survival than males.
- First-class passengers had higher survival rates.
- Fare and passenger class were correlated with survival.
