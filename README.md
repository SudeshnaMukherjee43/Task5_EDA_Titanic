## Task 5 – Exploratory Data Analysis on Titanic Dataset

This task focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset.

### Files included:
- Task5_EDA_Titanic.ipynb – Jupyter Notebook with full EDA
- titanic.csv – Dataset used
- Task5_EDA_Titanic_Screenshots.pdf – Screenshots of outputs and visualizations

### Key Observations:
- Majority of passengers did not survive the disaster
- Survival rate was influenced by factors like gender and passenger class
